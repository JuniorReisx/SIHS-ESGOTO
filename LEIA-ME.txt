PAINEL INTEGRADO DE SANEAMENTO RURAL — BAHIA
==============================================

O QUE VOCÊ PRECISA PARA ABRIR O PAINEL
-----------------------------------------
Abra o arquivo:
     painel_SIHS.html

Dê duplo clique nele e ele abre no navegador padrão (Chrome, Edge ou
Firefox recomendados). Não precisa instalar nada nem de internet.

IMPORTANTE: mantenha a pasta completa (painel_SIHS.html + pastas css/,
js/ e data/). O HTML referencia esses arquivos externos. Para enviar
a outra pessoa, compacte a pasta inteira em .zip — não envie só o .html.

ESTRUTURA DO PROJETO
--------------------
  painel_SIHS.html   — estrutura HTML do painel
  css/painel.css     — estilos visuais
  js/painel.js       — lógica do painel (mapas, filtros, abas)
  js/geo-data.js     — dados geográficos dos municípios
  js/pts-data.js     — dados dos 3.171 aglomerados
  data/*.json        — mesmos dados em formato JSON (referência)

O arquivo é grande (~2,7 MB) porque carrega o mapa e os dados de
todos os 417 municípios e 3.171 aglomerados de uma vez. Pode levar
alguns segundos para abrir, principalmente em computadores mais
lentos ou no navegador do celular — isso é normal.

PASTA "shapefile_municipios/"
--------------------------------
Aqui está o shapefile original dos limites municipais
(MUNICIPIOS_MEIOSOCIO_SANERURAL_2025.shp + arquivos complementares)
que foi usado como base geográfica do painel. Incluído para
referência/rastreabilidade — o painel NÃO precisa desses arquivos
para funcionar, eles só servem caso alguém queira abrir os limites
municipais originais num programa de GIS (QGIS, ArcGIS) ou conferir
a fonte dos dados geográficos.

COMO ENVIAR PARA OUTRAS PESSOAS
--------------------------------
Compacte a pasta SIHS inteira em .zip e envie. A pessoa deve
descompactar e abrir painel_SIHS.html mantendo as pastas css/, js/
e data/ no mesmo lugar.

O QUE TEM DENTRO DO PAINEL
----------------------------
5 abas, com filtro e consulta de município compartilhados entre todas:
  1. Água          — visão geral do abastecimento de água
  2. Esgoto        — visão geral do esgotamento sanitário
  3. Consulta Rural (Água)   — Aglomerados x Rural Disperso
  4. Consulta Rural (Esgoto) — Aglomerados x Rural Disperso
  5. Aglomerados   — mapa de pontos por prioridade (P1-P5)

Dados: Censo IBGE 2022, base "Revisado.xlsx" (setores censitários),
shapefile municipal MUNICIPIOS_MEIOSOCIO_SANERURAL_2025 (incluído
nesta pasta), e a classificação de aglomerados do Consórcio SaneRural.

Versão gerada em: verifique a data no próprio painel (canto superior
direito do cabeçalho).
